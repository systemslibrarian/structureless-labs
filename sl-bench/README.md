# sl-bench

**Benchmarks and parameter comparisons for the Structureless Labs ecosystem.**

Not a leaderboard. A lab notebook. Results feed parameter decisions (flight recorder) and
predictions (time capsules), and every result carries an evidence grade — typically C
(reproducible internal experiment).

## Scope
- Parameter sweeps for sl-kem (security estimate vs size vs speed).
- Reproducibility: every benchmark runs from a clean checkout with a pinned environment.
- Output: machine-readable results + a short written interpretation. Numbers without
  interpretation are not a result.

## Honesty note
sl-kem is optimized for long-term archival protection, not speed. Expect it to look
unimpressive on size/latency tables — that is by design (see sl-kem/decisions/D-0001).

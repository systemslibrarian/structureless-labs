# Evidence Grading

Claims in Structureless Labs are graded so readers know how much to trust them.

| Grade | Meaning | Example |
|-------|---------|---------|
| **A** | Standardized / peer-reviewed / formally proven | ML-KEM is NIST-standardized |
| **B** | Strong public consensus, not formally proven here | LWE hardness assumptions |
| **C** | Internal simulation or reproducible experiment | sl-bench parameter result |
| **D** | Reasoned argument, untested | "this margin should hold" |
| **E** | Speculation / open question | a time-capsule prediction |

Every security-relevant statement in a spec must carry a grade. Ungraded claims are
treated as grade **E** by default.

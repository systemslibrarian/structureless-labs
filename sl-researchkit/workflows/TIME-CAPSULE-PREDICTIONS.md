# Workflow: Crypto Time Capsules

Every release records confidence-scored predictions, graded later. This builds
intellectual humility into the project and a track record into the science.

## At release — write a prediction
```
Prediction 001
Date:       2027
Prediction: Current parameter set survives 5 years of public review.
Confidence: 35%
Evidence:   Current attack estimates (grade C/D).
```

## Later — grade it
```
Outcome:    Wrong | Still holding | Partially correct
Resolved:   2032
Lesson:     What this teaches about our estimation.
```

Predictions are never deleted. A wrong prediction kept on the record is worth more than
a quiet correction.

Decision ID: D-0001 (sl-researchkit)
Question:     What does "structureless" name primarily — a research method, or a property
              of a lattice construction?
Alternatives: (A) Research method (epistemic openness) is primary; the lattice-structure
                  echo is secondary and applies only to sl-kem as one design axis.
              (B) Lattice property is primary; the method is the cultural style.
              (C) Both equally; leave undefined (the status quo prior to this decision).
Chosen:       (A) — Method-first identity. KEM is the method's first test subject.
Reason:       The name foregrounded the highest-risk artifact (sl-kem) while the org's own
              stated bet says the primitive is not where the value is ("the highest-
              probability contribution is not a new hard problem — it is better analysis,
              methodology, integration, and tooling"). Option A aligns the name with the
              bet and prevents the apparatus from being read as a "new KEM" claim by a
              skeptical reader who has not yet read the prose.
Risks:        Some readers may still pattern-match the name to the lattice meaning on first
              glance. Mitigated by: an explicit "Why 'Structureless'?" section in the root
              README; a reframed sl-kem README that opens with "the method's first test
              subject"; the GitHub About description leading with method + explainers.
Evidence:     Grade D (framing / design-intent decision, not a measured result).
Reviewed by:  Principal Investigator — framed the tension between the name and the stated
                bet. VERDICT: PASS. Rationale: research question advanced; learning observable
                (whether the method produces evidence is now the test).
              Teacher — required that the new framing be explainable to a newcomer in plain
                language. VERDICT: PASS WITH NOTES — the "Why 'Structureless'?" section must
                land in the root README before merge. Note resolved by the same commit.
              Archivist — required the prior framing be fossilized, not deleted.
                VERDICT: PASS WITH NOTES — fossil entry required at fossils/. Note resolved
                by the companion fossil ORG-IDENTITY-PRE-OPTION-A.md.
              Cryptographer — the lattice-structure axis remains a legitimate sl-kem design

                sl-kem may continue to explore less-structured assumptions on the merits.
              Attacker — VERDICT: PASS. Reduces the credibility-attack surface of the org
                without weakening any technical claim; no new attack surface introduced.
              Engineer — VERDICT: PASS. No implementation impact; documentation-only.

# Contributing to Structureless Labs

Welcome. This lab runs on a specific culture; contributions are expected to honor it.

## The five principles
1. Conservative by default.
2. Break-it-first.
3. Nothing is deleted (fossils + standing predictions).
4. Explainable at three depths (Simple / Developer / Researcher).
5. Evidence over hype (everything is graded).

## Before you open a PR
- [ ] Map your change to a research question.
- [ ] Run the **PQC Red Team Checklist** (sl-researchkit/checklists).
- [ ] Obtain a **six-persona review** for significant changes
      (sl-researchkit/personas). For security-relevant changes, run an
      **AI-vs-AI cryptanalysis round** and link the report.
- [ ] Write a **decision record** for any significant choice.
- [ ] Fossilize, do not delete, anything you supersede.
- [ ] Add **three-depth explainers** for any new concept.

## Using the AI personas
Point your coding agent (Claude Code, etc.) at `sl-researchkit/personas/` and require all
six verdicts before merge. A single PASS is not enough; the Attacker and Cryptographer
hold real veto power.

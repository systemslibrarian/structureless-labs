# sl-attacklab

**Break-it-first cryptanalysis. The culture here is "Try to break this," not "Look how
secure we are."**

This is where genuinely new questions come from. The lab treats attacks — even failed
ones — as the primary product.

## Layout
```
targets/    Frozen design + parameter versions, open for attack.
findings/   Attack hypotheses, results, dead-ends. Nothing deleted.
```

## How to attack
1. Pick a target from `targets/`.
2. File a finding: hypothesis, method, result, confidence, evidence grade.
3. A failed attack is still logged — it raises the confidence floor and is on the record.
4. Confirmed breaks trigger a decision record + persona review in the affected repo.

## The "Attack Me" button
The public-facing surface (sl-atlas) links here with an explicit invitation. The point of
the project is to be challenged, not defended.

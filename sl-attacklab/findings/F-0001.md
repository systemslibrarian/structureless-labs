# Finding F-0001

Target:       sl-kem decision D-0001 — "Long-term archival protection (~40-year horizon)"
              (see sl-kem/decisions/D-0001.md). There is no spec version or parameter set
              to target yet; this finding targets the *claim itself* in its current state.
Attacker:     Attacker persona (AI), acting on the break-it-first mandate from
              sl-researchkit/personas/ATTACKER.md.
Hypothesis:   The D-0001 claim "Long-term archival protection (~40-year horizon)" is, as
              currently stated, **unfalsifiable** — and an unfalsifiable security claim
              violates the lab's own falsifiability principle (sl-kem/CONSTITUTION.md,
              Article 2). Specifically: there is no documented method to test the 40-year
              horizon; there is no concrete construction to attack; there is no parameter
              set against which to estimate concrete attack cost. A claim that cannot be
              attacked also cannot be defended.

Method:       Inventoried the entire sl-kem/ tree as of commit-at-review. Looked for:
                (a) a concrete construction (KEM algorithm description),
                (b) a parameter set with explicit values for `n, q, χ`,
                (c) any attack-surface listing (math, encoding, side channel, downgrade,
                    parsing, nonce reuse),
                (d) any cost estimate (lattice-estimator output, BKZ cost, etc.) against
                    those parameters,
                (e) any measurement, simulation, or even a draft estimate against
                    D-0001's stated 40-year horizon.
              Findings of the inventory:
                - CONSTITUTION.md  — method, not construction.
                - decisions/D-0001 — the claim being targeted; no supporting numbers.
                - fossils/SL-KEM-DRAFT-000.md — explicitly "No security claims."
                - predictions/PREDICTION-001.md — about future parameter revisions, not
                  about the 40-year claim.
                - spec/EXPLAINER-LWE.md — a primitive's *building block*, not a construction.
                - vectors/README.md — pointer only; no vectors.
              Net: (a)–(e) are all absent.

Result:       **Inconclusive — there is no design to attack yet.**
              This is itself the finding: a documented gap between a stated security
              claim and the existence of anything attackable.

Confidence:   90% in the procedural assertion "no attackable design exists in this repo
              as of 2026-06-09." 0% in any cryptanalytic claim about the 40-year horizon
              itself (no construction = no estimate).

Evidence:     Grade D — a reasoned argument about repo state, not a cryptanalytic result.
              (Per sl-researchkit/checklists/EVIDENCE-GRADING.md: "Reasoned argument,
              untested" = grade D.)

Raised:       Open questions this finding surfaces, for the next decision review:
              - When will a concrete construction land? (Without one, D-0001 cannot be
                tested by any persona.)
              - Is "40-year horizon" a *target*, a *claim*, or a *research question*? The
                grammatical mood of the current D-0001 reads as a claim; the evidence
                grade (D, design intent) suggests it should read as a target.
              - What attack outcome would falsify the claim? D-0001 does not say. Per
                principle 7 (humility / falsifiability), it should.
              - Should sl-kem publish a draft spec with attackable parameters *before*
                any further work on D-0001's horizon language?

Decision:     No decision record yet triggered. **Recommended follow-up: open D-0002 in
              sl-kem/decisions/** to either
                (a) reclassify D-0001's claim as a research question pending publication
                    of a draft spec with attackable parameters, OR
                (b) commit to publishing a draft spec (with parameters and an attack
                    surface) within a stated horizon, after which this finding can be
                    re-opened against the actual construction.

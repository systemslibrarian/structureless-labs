Hypothesis:   The D-0001 claim "Long-term archival protection (~40-year horizon)" is, as
              currently stated, **unfalsifiable** — and an unfalsifiable security claim
              violates the lab's own falsifiability principle (sl-kem/CONSTITUTION.md,
              Article 2). Specifically: there is no documented method to test the 40-year
              horizon; there is no concrete construction to attack; there is no parameter
              set against which to estimate concrete attack cost. A claim that cannot be
              attacked also cannot be defended.

Method:       Inventoried the entire sl-kem/ tree as of commit-at-review. Looked for:
                (a) a concrete construction (KEM algorithm description),
                (b) a parameter set with explicit values for `n, q, χ`,
                (c) any attack-surface listing (math, encoding, side channel, downgrade,
                    parsing, nonce reuse),
                (d) any cost estimate (lattice-estimator output, BKZ cost, etc.) against
                    those parameters,
                (e) any measurement, simulation, or even a draft estimate against
                    D-0001's stated 40-year horizon.
              Findings of the inventory:

                - decisions/D-0001 — the claim being targeted; no supporting numbers.
                - fossils/SL-KEM-DRAFT-000.md — explicitly "No security claims."
                - predictions/PREDICTION-001.md — about future parameter revisions, not
                  about the 40-year claim.
                - spec/EXPLAINER-LWE.md — a primitive's *building block*, not a construction.
                - vectors/README.md — pointer only; no vectors.
              Net: (a)–(e) are all absent.

Result:       **Inconclusive — there is no design to attack yet.**
              This is itself the finding: a documented gap between a stated security
              claim and the existence of anything attackable.

Confidence:   90% in the procedural assertion "no attackable design exists in this repo
